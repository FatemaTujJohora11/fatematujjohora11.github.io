*An introductory website adaptation of a topic from my LinkedIn LLM Basics learning series.*

Before a language model processes text, a **tokenizer** divides it into smaller units called **tokens**. A token may be a whole word, part of a word, punctuation, or another text unit.

For example, a tokenizer might split a longer word into smaller pieces. The exact pieces depend on the tokenizer used by the model.

Each token is mapped to a numerical ID. This gives the model a consistent way to handle text as data.

**Why does this matter?** Tokenization affects how text is represented, how much input fits in the model's context window, and how output is generated.

**Key idea:** Tokens are not always the same as words.
