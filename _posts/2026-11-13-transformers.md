*An introductory website adaptation of a topic from my LinkedIn LLM Basics learning series.*

A **transformer** is a neural network architecture that uses attention mechanisms to process sequences such as text.

A simplified language-model workflow is:

1. Text is split into tokens.
2. Tokens become numerical representations.
3. Transformer layers process these representations using attention and feed-forward networks.
4. The model produces scores for possible next tokens.

Different transformer models have different architectures. Many text-generating LLMs use **decoder-only** transformers, while other systems use encoder-based or encoder-decoder designs.

**Key idea:** A transformer is the architecture; a large language model is a trained model that may use that architecture.
